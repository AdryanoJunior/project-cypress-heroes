# End-to-End Test Automation – Cy Heroes

## About the Project

This repository contains test automation created for the study and practice of QA Automation using Cypress. 
Login (successful and invalid) and hero creation scenarios were implemented in the Cypress Heroes project.

## Tech Stack
Cypress
 – E2E testing framework

Node.js
 – Runtime environment

npm
 – Package manager


 ## Tested Features

 ### Login
 Login with valid credentials (success)
 Login with invalid username
 Login with invalid password
 Login with blank fields
 Login with invalid email format
 Error message validation

 ### Hero Creation
 New hero registration with valid data
 Validation of mandatory fields


 # Installation & Execution
1. Clone the repository
```bash
https://github.com/AdryanoJunior/project-cypress-heroes.git
```
2. Install dependencies
```bash
npm install
```

## Running
```bash
# You open the Cypress UI
npx cypress open
```
